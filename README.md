# Obninsk_Hakaton2

Hello everybody! Мы team_escape. Мы разрабатывали кейс 02 из направления "Городская среда", а именно "Цифровой волонтер Обнинска".

# Описание проекта
Проект решает проблему разрозненности данных волонтерской активности. Сервис переводит подтвержденные часы в прозрачную внутреннюю валюту по курсу 1 час = 10 койнов, исключает ручные ошибки и защищает систему от базовых злоупотреблений. meow
