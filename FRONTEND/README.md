# Frontend

React-приложение находится в **my-volunteer-app/**. Именно там лежат package.json, src и vite.config.js.

Общая инструкция запуска frontend и Django — в README.md корня проекта. Для Windows можно запустить Start-Backend.cmd и Start-Frontend.cmd из корня, затем открыть http://127.0.0.1:5173/.
